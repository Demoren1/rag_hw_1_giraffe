# Без контекста и две абляции: 15 пилотных вопросов

23 октября 2026 завершены три дополнительных прогона. Полная система
остаётся лучшей по точному набору вариантов и отказам: **14/15**.
Без семантического поиска — **12/15**, без первого вызова Qwen —
**10/15**, без контекста — **11/15**.

## Условия

Варианты используют те же 15 вопросов, ревизию Qwen3.5-4B, temperature=0,
thinking=false, до 1024 выходных токенов на вызов. Варианты с поиском
используют полный локальный корпус. Retrieval работает на CPU,
генерация — через прежний локальный
MLX endpoint на Apple GPU. Официального runtime пока нет. Gold читает
только оценщик после генерации. Три профиля зафиксированы до запуска;
повторных попыток по результатам нет.

- **Без контекста**, `config.no_context.json`: один вызов с вопросом
  и вариантами, без поиска, фрагментов и рабочей заметки. Разрешены
  собственные математические знания; SOURCES обязан быть NONE.
  Оценщик допускает пустые ссылки только у этого контрольного варианта.
- **Без dense**, `config.ablation_no_dense.json`: отключены EmbeddingGemma
  и векторный канал. Сохранены BM25, ограничения кандидатов и основных
  блоков, соседи, упаковка и два вызова. RRF получает только ранг BM25.
- **Один вызов**, `config.ablation_one_pass.json`: сохранены гибридный
  поиск и упаковка, удалён первый вызов с таблицей доказательств. Из
  финального промпта убраны инструкции сверять отсутствующую заметку.
  **Все 15 упорядоченных списков исходных блоков совпали с полной
  системой**; размер контекста специально не увеличивался.

Общий парсер и протокол REASON/SOURCES/CHOICES одинаковы у новых вариантов
и полной системы. Исторический BM25 baseline имел другой JSON-протокол
и промпт, поэтому его строка сравнивает реализации целиком. Вклад двух
компонентов проверяют абляции относительно полной системы.

## Вклад компонентов

**Семантический канал:** полная система исправляет q002, q009 и q015,
но ухудшает q012 относительно варианта без dense: суммарно +2 вопроса
(+13,3 процентного пункта) при стоимости на 16,0% выше. Без dense в q015
нижняя граница радиуса сходимости ошибочно принимается за точный радиус.
Эффект неоднороден: правильный ответ на q012 без dense требует проверки
цитат, нужные эталонные страницы в его контекст также не попали.

**Проверка вариантов первым вызовом:** исправлены q001, q002, q003 и q015
при тех же исходных блоках: +4 вопроса (+26,7 процентного пункта).
Стоимость выше в 2,35 раза. На пилоте выделенная таблица доказательств
полезнее прямого выбора по источникам.

**Без контекста:** решены 11 вопросов, все три отказа верны; ошибки
в q002, q003, q007, q012. Один вызов с контекстом исправляет q007, но
теряет q001 и q015: само добавление фрагментов не гарантирует улучшения.
Преимущество над историческим baseline нельзя приписывать только
retrieval: менялись также промпт и протокол ответа.

Это открытые примеры, использованные при разработке. Независимое
обобщение не измерено. Обоснования полной системы отдельно проверены
в [citation_audit.md](citation_audit.md): есть содержательные дефекты даже
при правильных вариантах. Сравнительный аудит всех пяти систем не проводился.
Официальные
Q, F1 цитат, E и итоговый балл требуют официальных корпуса/ID, gold,
runtime и evaluator; сейчас они не вычислены.

## Артефакты и воспроизведение

Новые ответы, trace, метрики и разборы находятся в
`local_data/comparison_v1/{no_context,no_dense,one_pass}/`. Старые строки
используют сохранённые `baseline_canonical` и `hybrid_canonical`, без
новых генераций. Все пять строк сведены в `experiments.csv`.

Новые прогоны: **45 ответов, 60 вызовов Qwen, 0 превышений лимитов**.
Usage подтверждён, локальные и серверные prompt token counts совпали
для всех вызовов. Код, профили, вопросы, gold и manifest индекса
зафиксированы хешами в `comparison_manifest.json`; проверка артефактов —
`artifact_checks.json`. Три процесса генерации с инициализацией заняли
75,46, 345,45 и 121,33 секунды соответственно.

Существующий парсер восстановил пропущенные названия полей в q006,
q013, q014 варианта без dense и q006 варианта с одним вызовом. Это
однозначные отдельные строки кодов: варианты и аргументы не менялись,
новых правил по результатам не добавлялось. Исправления видны в trace.
Вариант без контекста не потребовал таких исправлений.

Команда запуска `tools/run_comparison.py` приведена в `README.md`.
Автотесты не создавались и не запускались. Выполнены реальные прогоны,
проверка артефактов, синтаксиса и оформления Python.
